# Bareeq mobile app (Flutter)

One app for all roles. Step 11: customer screens. Technician and manager screens: step 12.

- Run on Chrome (laptop): see docs/SETUP.md, section "تطبيق الموبايل".
- Server address: `--dart-define=API_BASE=http://<server>:8000/api` (default http://localhost:8000/api).
- The address map is OpenStreetMap for testing only; it must be replaced by Google Maps before launch.
