# بريق (Bareeq)

تطبيق غسيل عربيات تحت البيت. المناطق: مدينة نصر، العبور، مدينتي.

## إيه اللي في المشروع ده

| الفولدر / الملف | فيه إيه |
| --- | --- |
| `CLAUDE.md` | التعليمات اللي Claude Code بيقراها أول ما يفتح المشروع |
| `docs/SPEC.md` | وصف البرنامج كامل: الشاشات، الأدوار، المواعيد، الدفع، المحفظة، والمراحل |
| `design/brand-kit/` | الهوية: اللوجو، الأيقونات، السوشيال ميديا، ودليل الهوية |
| `design/demo/index.html` | الديمو القديم اللي العميل شافه (كان باسم مؤقت «لمعة») |

البرنامج نفسه هيتبني في الفولدرات دي لما نبدأ:
`backend/` السيرفر، `mobile/` التطبيق (للعميل والفني والمدير كلهم).
